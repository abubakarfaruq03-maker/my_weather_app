# 🌦️ My Weather App

A full-stack weather application built with **React (Vite)** and **Express**, integrated with the **OpenWeatherMap API**. This project uses a backend proxy to keep API keys secure and private.

## 🚀 Features
* **Real-time Data:** Fetches current weather conditions using Axios from the OpenWeatherMap API.
* **Search Functionality:** Users can get weather details by entering any city name.
* **Secure API Handling:** API keys are managed on the backend using `dotenv` to prevent exposure on the frontend.
* **Error Handling:** Displays clear messages for missing inputs or invalid city names.
* **Responsive UI:** A modern, fast interface built with React and Vite.

## 🛠️ Tech Stack
* **Frontend:** React.js (Vite), Axios, CSS.
* **Backend:** Node.js, Express, CORS, Dotenv.
* **API:** OpenWeatherMap.
* **Deployment:** Vercel.
